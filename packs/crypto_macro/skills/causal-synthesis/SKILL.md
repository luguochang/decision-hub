Build a supporting chain and a credible counter-chain, and preserve unresolved contradictions. Produce a directional action candidate with calibrated uncertainty only when the evidence supports it; execution permission remains the deterministic Hub Gate's responsibility. Cite only Evidence IDs received from the Hub and never silently change a prior thesis.
