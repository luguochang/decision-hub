# Database Migrations

Alembic 是数据库结构唯一真源。应用启动执行 `upgrade head`；测试可以使用空库迁移或显式的 `Base.metadata.create_all` 测试 fixture。生产代码不能自动调用 `create_all`。当前 head 为 `0024_dsh_prompt_generations`；`0011` 增加 Core-owned ResearchMemo、Feedback 和 Capability intake，`0012` 增加不可变 Dataset/Experiment/Candidate、Promotion 决定和 CAS ActivePointer，`0013` 补齐 Promotion 幂等/评测族不变量，`0014` 增加实验 metadata 与 Experience 资产，`0015` 补齐 dataset/experiment/result 的 PIT provenance 与 candidate 归属，`0016` 增加 durable Evolution Job/lease 和 service heartbeat，`0017` 增加 Research Evidence lineage、Trigger/Decision Snapshot metadata 和 Run 的 decision snapshot ref，`0018` 为长运行 Run 增加可回收 lease，`0019` 增加 scheduled research child Run 的 `available_at` 与 `parent_run_id`，`0020` 增加规范化 Research Result/Trace/Command，`0021` 增加可选的研究 Trace 错误 provenance JSON，`0022` 增加 DSH session link 协调状态，`0023` 增加 durable DSH prompt projection，`0024` 允许同一 DSH Session 按 generation 保存不可变的多轮 Prompt。DSH session/插件状态仍不是业务账本。
