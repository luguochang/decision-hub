## 用户问题与已确认原因

1. **报告保存后，质量、上下文及下载读取超时。** 33版真实 BTC 报告的三个入口均在约45秒超时。32版原报告和首次失败继续保留，不能用启动成功替代功能成功。
2. **消费者版本接线漏项。** 32版已发布的质量检查器增加了完整用量原件读取，但保留报告的消费者适配仍只识别旧检查器。真实32的归档在33版已经注册；消费者不匹配使读取退出优化路径，进入昂贵回退。私库第二次完整控制被明确中止，结果是 interrupted/unknown。
3. **保留报告投影遗漏用量。** 当前报告读取会传递已认证的用量原件，保留报告投影没有该字段。修复须无损传递原件；缺失仍为 null，不能编造 token 或费用。
4. **历史采集发生网络中断。** 首批180日任务实际104完成、75失败、1不完整；两币各52日完成。错误均为连接不可用，不是ETH字段或行情解析问题。首批原件保留。后续同一失败URL的默认网络路径恢复返回200、业务码0和300行真实行情；直连仍为DNS错误，不能宣称已找到当时网络故障的全部原因。
