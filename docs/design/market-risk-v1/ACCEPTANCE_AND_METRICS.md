当前代码、数据库、API、PC动作与逐项执行门的对应见[架构与交付验收](CURRENT_ARCHITECTURE_AND_DELIVERY.md)；最新真实结果以[当前任务](CURRENT_FOCUS.md)为准。


版本：design.v1。**金融阈值与晋级门是首轮预登记提案，尚未证明预测价值，也不是金融安全保证；已通过的工程指标以命名回执为准。** 修改阈值必须产生协议新版本，保存理由，不能在看见试验结果后放宽同一次晋级门。

## 1. 默认协议参数

| 参数 | 默认提案 | 用途/限制 |
|---|---|---|
| scope | BTC-USDT、ETH-USDT，OKX spot/trade/USDT | 新研究scope须准入；现有swap与日规则身份保持 |

| 深度研究报告 | 24h观点；定时/事件触发，窗口不早于实际发布 | 显示实际cutoff/发布延迟/风险资格；与数值影子对象分别绑定，不覆盖原预测 |
| 价格分辨率/调度 | 完整closed 1m bar；poll/tick 60s | 首次穿越精度为1m区间；不承诺秒级或成交价 |
| 滚动事实条件 | 最近完整30m的绝对close return；BTC≥1.5%、ETH≥2.0% | 试用阈值；触发是事实变化提醒，不当事前预测成绩 |
| 告警episode | 条件触发一episode，持续true不重复；恢复false后才能形成新episode | 同一episode严重度升级可新增transition；unknown不解除 |

| 数据陈旧 | 最新closed bar结束距now>180s；连续2次取数失败立即degraded | 恢复必须有新合格输入；暂停/过期不称风险解除 |
| 路径标签 | adverse幅度2%、5%两档；主评价固定2%，5%为敏感性 | 按长/短分别评价，非止损或清算线，不能事后选最优档 |
| 实验概率 | 历史目标90日，至少60个完整非重叠窗口才显示实验频率 | 仍未校准；不足返回null。窗口已结果成熟且PIT合格 |
| 影子诊断期限 | 固定28日历日 | 到期出优势/无增益/不足结论，工程可结项，未合格模型不晋级 |

## 3. 产品价值与模型指标

每次报告列出预登记机会数N_expected、发布数N_published、按时发布数N_on_time、已到期数N_due、认证标签数N_verified、可评分概率数N_prob、报警/事件episode数和完整监控资产日。N_due以全部预登记标签窗口已结束计数，包括该次未发布/late/弃权的机会，不仅选已有成功预测；N_verified是这些机会中完整原件已认证标签数。late输出保留在账本但不进入主配对，公开因此缺失的覆盖。分母为0返回null，不报100%。

| 指标 | 公式/分母 | 用途 |
|---|---|---|
| 发布覆盖 | N_published/N_expected | 未发布、失败、弃权分别计数 |
| 按时发布覆盖 | N_on_time/N_expected | late单列，不能改窗口或回填原时点 |
| 成熟标签覆盖 | N_verified/N_due | 未成熟另外列，不当错误 |
| 概率评分覆盖 | 同时有合格概率和标签的数量/N_due | 搭配概率可用数/发布数，不隐藏unknown |
| 方向准确率 | 正确/预登记可评分方向标签 | 中性/弃权单列，不能强造涨跌标签 |
| Brier损失 | mean((p−y)^2) | y为冻结的长/短MAE越界事件，非own_action_correct |
| 配对增量 | mean(loss_baseline−loss_candidate) | 正值有利；只在相同可评分配对计算，公开配对覆盖 |
| 分位损失 | mean((τ−1[y<qτ])×(y−qτ)) | 目标和τ冻结，检验风险区间质量 |
| 区间覆盖/宽度 | 命中区间数/N_verified_intervals；mean(width) | 区间不能靠无限放宽获得成绩 |
| 事前报警精确率 | 匹配有效未来事件的报警episode/可评分报警episode | 重复通知不增加命中；时序不确定单列 |
| 事件召回 | 有有效提前报警的事件episode/完整暴露下可评分事件episode | 同时报实际监控暴露覆盖与中断中的事件 |
| 误报负担 | 未匹配报警episode/完整可评分资产日 | 未知报警和缺数据资产日另列 |
| 提前量 | 事件区间−真实可见时刻 | 若事件区间为[e1,e2]、可见为A，报告[e1−A,e2−A]；下界>0才确认为事前 |
| 反应时延 | 事实known→求值→可见各段 | 与事前预警分开；补发不重写过去时刻 |

所有记录入账，但未知/缺标签不能被强制标预测错误。既有authenticated `coverage_ratio=count/len(samples)`是样本外已评估数/输入数；其目标是own_action_correct，不能改称暴跌概率或报警覆盖。

### matching.v1：报警与事件怎样配对

这个协议与预测模型版本分开冻结，注册时保存hash。以下为首轮确定性提案：

1. **主事件定义**：固定每日24h窗口、指定首bar锚点、scope/venue/price_type/direction/δ；首次完整bar越界产生一个event_presence，保存[e_low,e_high]。每window/方向/阈值至多一个主事件。缺bar时presence与firstness分开，主评分资格不足。
2. **episode与聚类**：通知重复按同alert_id不计；同rule连续true属于同报警episode。事件主标签按固定窗口保留；同scope/方向相邻首穿越区间距离≤30min归同market_episode，不能重复计主事件命中。BTC/ETH同期发生按UTC日block及已知共同事件ref归组做CI，成因未知时只称时间相关组，不猜操纵。
3. **可配报警**：只有`alarm_kind=forecast_risk`纳入事前成绩，要求prediction/model/target/version及实际可见通道相符；默认shadow策略p≥0.20、主目标长仓2%、有效窗为prediction固定window。该概率策略是待验证提案，未具资格不作为正式杠杆提示。30m事实变化/data_health报警单独算反应，不纳入事前命中。
4. **匹配规则**：scope、方向、阈值、价格类型一致，事件在报警有效窗内，提前量下界≥5min；按event时间→alert可见时间→稳定ID排序，一对一匹配。一个alert episode最多匹配一个market_episode；一个market_episode最多认一次主命中。同事件其他独立报警不加真阳性，记录unmatched/redundant负担，重复通知仍不算新episode。
5. **未知处理**：无完整监控暴露、无display/渠道ack、事件时刻区间跨提前量边界、price basis不匹配均不可评分并记录原因，不强标TP/FP。完整暴露覆盖与可评分覆盖一起公开；可评分内有效窗结束却无匹配的forecast报警才进入误报负担。不能把停机中事件从全量事件账本删掉。
6. **通道/样本身份**：站内published仅支持“列表可用提前量”；实际PC显示/渠道送达协议单独评分，测试observer与真实用户分组。用户页面关闭时实际送达未知；测试保持页面打开不能证明用户已收到。matched_pair保存alert/event ID、time bounds、protocol/hash、eligibility及exclusion理由。

数值影子输入在00:00前实际known的快照中冻结；截止后工具新取资料不能进入该配对特征。深度研究可以独立查证并给出新的实际cutoff报告，但不能用其后来材料重算原数值预测。固定00:01首bar缺失维持anchor未知；late发布不移到00:02后重新算作按时预测。

## 4. 资格门与固定试验

### Q01 工程/研究试用资格

A01–A27及O/U中适用门有实际回执；无未解释核心失败；实际scope/version可核验。若未完成用户验证或自然报警样本，则交付状态为受控试用/边界明确，不能写全面验收通过。

### Q02 统计输入资格

每scope/horizon/target至少100个认证时间block、PIT越界0、标签完整率100%；这是协议下限，不能当充分统计保证。固定主目标长仓2% MAE越界，短仓及5%为独立/次要结果。tail事件资格暂设至少30个不同事件block作为最低观察门，功效探针还须核对该下限能否给所需精度；不够就延长独立观察或维持不足，不伪造样本。

BTC/ETH同一冲击、重叠窗口、同题重复不算独立。样本外拆分按时间，embargo至少最长24h标签窗；训练时仅用结果已知的标签。prospective试验结构须新增risk目标的合同与认证，不直接向旧通用JSON塞新目标。

### Q03 模型增量晋级提案

一主基线一候选；同cutoff、同输入、同标签。默认主目标配对Brier增量≥0.005且按日/事件block的95%置信下界>0；0.005是最小实用效应提案，须在试验前通过基率/功效评估确认。事前冻结bootstrap或其他CI方法和random seed，测试集不参与调参。

风险报警策略为独立门：默认误报≤0.2 episode/完整资产日、事件召回≥60%，必须同时给出95%区间及暴露覆盖；主事件提前量下界≥5min才算事前命中。以上用途阈值是提案，不是市场可达到的已知水平。功效探针判断它们不可辨识或不可达时，进入协议修订并注册新试验；不能给原试验事后换门。

分位/区间候选还需主分位损失配对改善，名义覆盖与置信区间兼容、宽度相对基线不退化；重要状态子组无明确退化。风险概率资格不能由某一报警规则的命中率替代。

### Q04 有限结项

28天shadow到期输出可评分数、缺失、事件数、所有指标、CI、误报、成本和状态子组。允许`no_gain`或`insufficient_evidence`结束当前实验，正式指针保留基线、资格不升级。可选择新的独立观察周期，不能在原周期里反复改模型追涨跌。

### Q05 AI/记忆质量

实际合同和已执行的 20 项工程控制见[执行索引](CONTRACT_AND_Q05_EXECUTION_MAP.md)：20P，93份调用前输入；首轮18P/2未执行保留，补跑仅2项，合并分母XML明确标注。20真实市场材料、模型理解和两方法真实比较仍未执行；工程控制通过不授完整Q05。
