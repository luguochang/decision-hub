## 同一任务报告整理失败后的恢复


研究过程有结果，不等于完整报告已经确认保存。以“这份研究能支持什么”的整理状态和下载入口为准。

**当前入口范围：** 已取消且未保存完整报告的任务，以及指定的数据核验失败状态，可以查询恢复条件。条件允许仅代表可请求整理原研究，实际保存仍需后台通过。已经保存但独立确认失败的任务不适用此入口，其专用恢复分支尚未交付。不把重复点击当作解决办法。以下为未保存任务的恢复流程说明。

1. 点击“核对恢复条件”，仅查询当前条件。
2. 条件允许时，点击一次“恢复本次报告整理”。这会请求整理原研究，不创建另一研究任务。
3. 等待“已读取确认保存的报告”，再下载完整 JSON 或阅读版。请求已接受只表示开始恢复，尚不代表报告已保存。
4. 如果请求未确认、页面刷新或浏览器返回，点击“核对原恢复回执”。原请求会保留；页面刷新不会自动重新提交。需要明确重试时使用“核对并按原请求重试恢复”，复用原请求。
