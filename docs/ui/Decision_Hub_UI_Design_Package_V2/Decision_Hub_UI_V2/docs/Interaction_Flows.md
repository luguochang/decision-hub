# 交互、页面目录与返回协议

## URL 与上下文

原型使用 hash 路由，不依赖服务器路径重写。例：

```text
#/report?run=demo-r01&back=%23%2Fruns%3Fq%3DBTC
#/evidence?run=demo-r01&evidence=EV-001&back=<编码后的来源 URL>
#/graph-node?run=demo-r01&node=round-2&back=<报告 URL>
#/document-review?doc=demo-doc&run=demo-r01
```

`run`、`doc`、`event`、`evidence`、`node` 是对象身份；`back` 是白名单内的来源路径。关键词和筛选值同步到 URL。打开下钻页面时保存滚动及触发元素 ID，退出恢复同一来源，而不是硬编码“回首页”。直接打开深层链接没有来源时使用明确兜底：图谱 / 证据回同 Run 报告，DSH 回同 Run 技术页，资料回资料库，事件回日历。

首轮检查确实发现一个问题：筛选通过 `replaceState` 更新，行链接里的旧 `back` 没有更新。已在 `updateQuery()` 中同步这些指向当前来源的下钻返回地址，并分别回归任务筛选与日历筛选。这样不只是补一颗返回按钮，而是保存返回时应恢复的状态。

## 操作链路

首页 → 输入 → submitting → queued → researching → 对应报告。报告 → 技术详情 / Evidence / 图谱 → 同一报告。日历 → 指定事件 → 原筛选列表。资料库 → 上传 → 解析 → 逐块审核 → 显式确认 → 质量复检 → 新 Run → 报告中的资料入口 → 原资料版本。技术详情 → DSH → 原技术页。

原型没有真实服务端；上述创建、解析、校验是本地演示。图谱展示的是结构化证据和运行关系，不是模型私有逐字思维链。

## 键盘与焦点

`Ctrl / Cmd + K` 打开评审目录；输入页 `Ctrl / Cmd + Enter` 提交。Esc 关闭弹层；图谱 Esc 先关闭节点检查器，再退出图谱。弹层打开时背景 inert，Tab 限定在弹层内，关闭后恢复触发位置。图谱支持方向键、加减缩放与 F 适配，并提供列表视图。没有为触屏只保留 hover 操作。

## 38 个桌面页面 / 状态

以下 38 项是页面与状态，不是 38 个独立业务模块。六个移动视图是同一响应式原型的重点截图，不另建一套业务逻辑。

| 编号 / 路由 | 入口 | 主要操作与反馈 | 返回与约束 |
|---|---|---|---|
| D01 `home` / 研究指挥台 | 工作台；侧栏 Research | 输入可选关注点、打开当前任务、事件和报告 | 报告等深层返回 home 并保持 Run |
| D02 `compose` / 获取最新操作建议 | 首页主行动；报告重新研究 | 填写或留空；开始分析；显示原范围 | 返回来源页，保留草稿 |
| D03 `submitting` / 提交中 | 提交中；评审目录 | 只读输入，按钮锁定；登记同一意图 | 可查看任务；没有第二次创建 |
| D04 `queued` / 研究已排队 | 已创建 Run | 显示入账与等待 Worker；可离开 | 返回来源；离开不取消 |
| D05 `researching` / 正在研究 | Worker 研究中 | 轮次、工具数、最近活动；查看技术详情 | 离开保留 Run；完成不强制抢焦点 |
| D06 `failed` / 研究失败 | 提交或来源失败 | error code / origin / retryability；保留修改后输入 | 重试生成关联记录；失败旧记录保留 |
| D07 `runs` / Research Runs | 侧栏与报告返回 | 关键词、状态、触发类型筛选；父子任务 | 打开报告再返回保留筛选 URL |
| D08 `calendar-all` / 宏观事件 · 全部 | 工作台；侧栏 | 市场 / 重要性 / 关键词；事件抽屉 | 关闭抽屉恢复当前条件 |
| D09 `calendar-upcoming` / 宏观事件 · 即将发生 | 日历范围标签 | 同一账本的未来风险窗口；来源状态 | 范围在 URL；不创造历史实际值 |
| D10 `calendar-history` / 宏观事件 · 历史发布 | 日历范围标签 | 真实 0 项空态、覆盖范围、来源问题 | 返回全部 / 工作台 |
| D11 `event` / 事件详情抽屉 | 指定 event_id | 查看各数值、来源、观察时间和版本 | 关闭 / Esc 返回来源日历及筛选 |
| D12 `report` / 研究报告 | 指定 run_id；完成后 | 查看方向、周期候选、依据、限制；重新研究 | 返回来源任务列表或工作台 |
| D13 `report-incomplete` / 结论不完整 | synthesis_incomplete Run | 提示论证不完整；看缺口和父任务 | 父子任务双向返回；不覆写旧报告 |
| D14 `technical` / 技术详情 | 当前 Run 报告 | 八模块折叠；证据、图谱、技术排查 | 返回同 Run 报告及滚动位置 |
| D15 `evidence` / 证据详情抽屉 | 报告 / 技术页 / 图谱证据 ID | 真实对应 ID；来源和关联节点 | 关闭 / Esc 返回原节点或原报告 |
| D16 `graph` / 全屏分析链路 | 报告全屏分析链路 | 缩放、Fit、拖拽、Mini Map、搜索、筛选、分组、列表 | 退出 / Esc 返回报告原滚动和焦点 |
| D17 `graph-node` / 图谱节点检查器 | 图谱节点 | 节点检查器；证据打开；定位当前节点 | 关闭检查器保留图谱；退出回报告 |
| D18 `library` / 研究资料库 | 工作台；侧栏资料研究 | 资料状态、版本与关联任务；上传入口 | 回工作台；指定资料保持 doc_id |
| D19 `upload` / 上传资料 | 资料库上传 | 文件格式与必填字段校验；隐私模式提案 | 返回资料库；本地仅处理元数据 |
| D20 `document-uploading` / 资料上传中 | 提交上传；评审预览 | 模拟上传进度与元数据 | 回资料库，不丢文档条目 |
| D21 `document-parsing` / 资料解析中 | 上传完成；重试 | 结构提取状态；原文保留 | 解析完成再进入审核，不提前通过 |
| D22 `document-quality` / 资料质量不足 | 质量门不足 | 硬缺口与具体块；回到审核定位 | 不允许直接接入研究 |
| D23 `document-review` / 语义修正审核 | 解析完成；资料详情 | 原文 / 建议；逐条接受拒绝；敏感变化阻断 | 保存草稿；返回不覆盖原文 |
| D24 `document-confirm` / 确认审核范围 | 差异全部处理 | 确认审核范围与显式勾选 | Esc / 继续核对回当前版本审核 |
| D25 `document-confirmed` / 质量复检中 | 人工确认后 | 新版本进入独立质量复检 | 确认不等于质量门直接通过 |
| D26 `document-ready` / 可用于研究 | 质量门通过 | 结合此版本发起新研究；查看版本 | 携带 doc 和 version，不能混用未确认版本 |
| D27 `document-linked` / 资料已连接 | 资料接入研究 | 打开关联 Run；看被引用版本 | 资料到报告、报告到资料双向链接 |
| D28 `document-failed` / 资料解析失败 | 解析异常 | 错误码、重试和保留的文件信息 | 重试同文档处理；不静默丢失 |
| D29 `home-loading` / 工作台加载中 | 首页资源未读完 | 分别显示 worker / 日历 / runs 读取 | 避免空白大卡或假报告 |
| D30 `home-unknown` / 服务状态未知 | 心跳未确认 | 明确未知；查看服务与来源 | 未知状态也携带到状态详情 |
| D31 `home-degraded` / 来源降级 | 部分来源失败 | 来源、受影响范围、最后成功、下次检查 | 可查看详情或重新研究；不等于授权 |
| D32 `home-empty` / 暂无研究任务 | 真实无任务 | 原因说明；可发起研究或上传资料 | 不把演示报告当空态数据 |
| D33 `sources` / 服务与数据源 | 顶栏健康状态 | Worker、来源、采集缺口分别显示 | 返回来源页与健康上下文 |
| D34 `states` / 组件与状态规范 | 左下评审入口 | 令牌、图标、反馈、危险操作确认样例 | 只用于交付评审，不是业务功能堆叠 |
| D35 `dsh` / DSH · 技术轨迹 | 当前 Run 技术页 | 内部提示；日志筛选和选中详情 | 携带同一 Run 返回 Hub 技术页 |
| D36 `dsh-conversation` / DSH · 对话摘要 | DSH 页签 | 公开运行摘要；不含逐字思维链 | 保持 Run / Session 映射上下文 |
| D37 `dsh-research` / DSH · 主动研究 | DSH 页签 | 子任务、状态、失败与运行摘要 | 技术内容不变成第二份用户建议 |
| D38 `dsh-report` / DSH · 原生报告 | DSH 页签 | 原生技术记录占位；打开 Hub 报告 | 不把 Session JSONL 当 Evidence |

截图路径、页面尺寸和对应 URL 详见 `screen-manifest.json`。冻结状态使用 `preview=1`，只用于演示目录；正常业务流程不应携带该参数。
