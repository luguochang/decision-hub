# 实际检查记录与剩余验收

## 执行范围

本次使用 Chromium + Playwright，把最终交付的单文件 HTML 直接注入浏览器页面执行。没有访问网络、后端 API、真实行情、模型或用户文件上传接口。全部 38 个桌面页面 / 状态完成渲染检查；6 个移动端重点视图检查宽度溢出。重点交互使用真实点击、键盘、选择框、图谱拖拽与浏览器历史执行，不是只审查代码。

最终 **39 项检查通过，0 项失败，0 个未处理 JavaScript 异常**。原始结构化结果在 `qa/results.json`，实际日志在 `qa/final-run.log`，脚本在 `qa/run_checks.py`。这不等于 39 项生产端到端验收，也不意味着所有可能的交互组合已覆盖。

## 首轮发现并修复的问题

首轮 39 项中有 2 项失败：任务列表筛选后进入报告再返回，筛选条件丢失；日历筛选后打开事件再关闭，来源条件丢失。原因是 `replaceState` 更新筛选时，之前渲染的下钻链接仍保存旧 `back`。

修复：在 `updateQuery()` 中同步更新指向当前来源 URL 的下钻链接。随后重新运行完整检查，两条故障均通过。保留 `qa/round-1-results.json` 与 `qa/round-1.log`，不删除失败记录来营造一次通过的印象。

视觉复核还修正了品牌副标题换行和质量状态 Badge 拉伸，重新检查桌面与移动端。最终交付截图由同一原型生成，长页另附全高 PNG。

## 检查覆盖

主链包括空输入提交、同窗口幂等、提交锁定、queued / researching / completed、离开不取消、重新研究父子关系和失败重试保留编辑输入。上下文包括任务筛选、事件筛选、父子 Run、Evidence 抽屉、图谱节点、退出全屏的滚动与焦点、DSH 同 Run 返回和资料 / 新 Run 双向关联。

图谱包含放大、缩小、Fit View、拖拽、方向键、Mini Map 定位、筛选、搜索空态、工具分组折叠和列表切换。资料包含必填与格式校验、敏感建议阻断、原文不变、逐块审核、显式确认、独立质量复检和硬缺口阻断。

界面抽查包括真实空态、unknown 不显示绿色、无凭据交易授权、图标操作可访问名称、弹层 Tab / Esc、桌面与移动整页横向溢出。额外验证 78 个 SVG 可解析、未把位图包装为 SVG，并计算 8 组语义前景/背景对比度，均达到 4.5:1；详见 `qa/assets-and-contrast.json`。

## 审查方式说明

采用视觉、业务状态、导航恢复、前端交互和无障碍抽查几个角度的顺序复核，加上自动化执行。当前工具环境没有提供独立子 Agent 调度，因此没有宣称“多 Agent 并行对抗通过”，也没有第三方团队签字。原始测试结果比角色命名更重要。

## 环境限制与未覆盖项

运行环境对本地文件和本地 HTTP 导航有策略限制，直接导航返回阻止错误。本次没有绕过策略，使用 `set_content` 进行离线 DOM 执行。单文件打开、HTTP 资源加载与真实浏览器刷新后的会话恢复未在该受限导航模式下验收。

未覆盖真实 API 数据一致性、服务端幂等、身份权限、原始文件上传 / OCR、真实质量检查、云端持久化、跨标签页协作、Safari / Firefox、屏幕阅读器完整流程、系统高对比度、全部 200% 放大场景、大图和大列表性能。仅确认指定视口无整页横向溢出，不声称每个复杂内容控件绝无局部滚动。

生产接入前以上项目均需补测；尤其要把模拟计时器与固定 fixtures 替换为真实合同后再验收。测试脚本只断言本包演示行为，不验证真实产品已经具备这些能力。
