# 素材使用与来源

`icons/svg/` 含 64 个 24×24 viewBox 线性图标，对应 `icons/png/24/` 与 `icons/png/48/`。`features/svg/` 含 12 个 64×64 功能图标，对应 128px PNG。`logo.svg` 为品牌几何重建，`icons/sprite.svg` 聚合线性路径。

这些 SVG 是实际 path / rect / circle 等矢量结构，不含嵌入 PNG。它们由本交付可编辑源码生成，沿用并扩展前版会话交付中的路径，并根据最新设计调整风格；没有声称由 image2 直接输出原生 SVG，也不冒充第三方付费图标库。

`backgrounds/hero-landscape.png` 为本次会话首页设计图的精确装饰裁剪，568×130，不建议无限放大。`reference-crops/` 的按钮、图标与证据卡切片只作视觉核对，不用作功能按钮或正文。

原设计 PNG 位于 `references/`。它们包含生成文字和未经验证的示例值，只能作为视觉参考。前端应使用 `tokens.css` 与状态规范，不能照抄其中冲突的数字和标签。

SVG 颜色可通过路径属性或内联 currentColor 适配；小图标建议 16–24px 显示，关键功能图标建议 40–64px。重要状态必须同时有文字，不只靠图标颜色。业务表格与图谱节点不宜栅格化。

未附带字体文件。使用系统字体回退；不要把字体目录复制进重构仓库。本包不提供第三方权利保证或独立法律审核。
