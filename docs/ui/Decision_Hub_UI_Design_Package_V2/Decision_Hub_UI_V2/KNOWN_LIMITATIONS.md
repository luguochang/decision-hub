# 已知限制

交付物是设计规范、可编辑前端参考和离线交互原型；不是已部署的生产系统。没有修改用户仓库、推送代码或调用真实 Hub / DSH API。

示例中的日程、时间、数量、价格曲线和解析进度是明确标注的演示数据。生成参考图也不是事实来源。未支持的真实数据不能靠这些样例补齐。

本地模拟只保存文件元数据，不真实上传、解析或执行质量检查。没有真实权限控制、跨会话云端持久化、模型调用和交易能力。服务端未知合同见 `docs/API_Contract_Map.md`。

使用 sessionStorage 的本地会话存储在不可用时退回当前页面内存；不承诺浏览器关闭后恢复。真实登录态、刷新恢复、并发编辑与多人协作待生产实现。

生成图片保留为 PNG 参考，没有伪造可编辑 Figma 文件。可编辑部分是 HTML/CSS/JS、SVG 路径与文本规范。没有提供任何字体文件。

39 项浏览器检查是原型验证，非全量生产认证；没有独立多 Agent 执行。直接本地文件 / HTTP 导航在本环境被策略阻止，使用同一 HTML 的浏览器 DOM 注入进行检查。详见 `docs/QA_Report.md`。
