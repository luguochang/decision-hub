# 复盘文档

本目录保存产品和工程失败复盘、根因和可迁移的长期教训。复盘记录事实和改进约束，不替代 ADR、产品规格、Stage Charter 或 canonical schema。

- [2026-08-30 Decision Hub 产品失败复盘与长期工程教训](RETRO-2026-08-30-PRODUCT-FAILURE-AND-LESSONS.md)

维护规则：

1. 复盘必须区分事实、推断、根因和行动项。
2. 不用复盘文档直接授权代码或修改 active pointer。
3. 需要跨模块决策的行动项必须落到独立 ADR；需要实现的行动项必须落到 Stage Charter。
4. 不删除失败样本、历史运行或已经证明的负面结果。
