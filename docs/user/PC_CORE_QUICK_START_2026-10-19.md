# BTC/ETH PC 核心流程使用说明

本指南说明使用路径。最新通过项、未通过项与截图以同日期 `PC_CORE_ACCEPTANCE_2026-10-19.md` 为准。

## 1. 打开与首次设置

1. 使用产品启动后生成的本机“Decision Hub”入口；首次打开会自动建立本机使用会话。
2. 首页点击“查看已保存设置并研究”，读取 BTC 当前合约规则；要让同一模拟账户支持 ETH，也先读取 ETH 规则。
3. 首次模拟在下方账户区点“重新读取模拟账户”，再填写模拟资金、选择“看到方案后手动确认”并勾选确认，创建账户。没有默认余额，也不会连接真实账户。回到上方，将“账户来源”设为“已保存的模拟账户”并选择这个账户。
4. 填写适用的仓位、风险设置，选择4/24/72小时，保存。系统会显示保存结果；保存不等于研究已经更新。

## 2. 研究与判断

- 点击按当前已保存设置研究。后台运行期间可以离开页面，再从原任务打开；无需填写研究问题。
- 原请求已确认后，可点“重新研究当前已保存设置”明确开始一次新研究；同一设置不需修改才能重做。历史请求和回执保留可核对。
- 请求结果未知时，先“核对原研究回执”。若服务端仍未找到，使用“关闭未受理请求”明确关闭原命令；服务端如已受理，会恢复原任务，不会取消它。只有收到已关闭回执后，才可明确开始新研究；关闭过程超时仍应核对原回执，不重复提交。
- 同一次研究的报告、建议卡和原回执应对应同一任务。进度页显示失败时先查看具体原因，不把排队或取到行情当作研究成功。
- 建议先看“当前首选”，再看多空/维持比较、三类概率以及原报告中的根因链、反方观点、确认与失效条件。
- 事件发生概率、事件发生后的结果概率、市场方向概率和假设成交下的盈利概率口径不同；当前主观研究估计没有统计胜率证明。比较单位不是投入金额。

## 3. 持续研究

在已保存设置下显式启用“持续研究”。首次从下个整点开始，每小时登记一个机会；立即需要结果可手动发起。可以暂停，查看下一槽位、原启停回执与最近任务。暂停研究不会撤销已存在模拟持仓的退出保护。

## 4. 手动模拟

当前实现 **BTC/ETH、4小时、模拟账户空仓、首选开多或开空**，工程链已验证，正式Chrome真实报告和纸面成交仍待通过：

1. 在可用建议下准备手动模拟。
2. 明确填写本笔最多名义金额、止损/止盈触发价、最晚退出时间，并确认模拟。
3. 提交后先显示排队，实际模拟成交由后台正常队列取得下一笔合格盘口后决定。读取执行状态核对成交价、张数和交易费。
4. 保护触发后，后台按反应时间及后续合格盘口退出；不是按止损价回填成交。原执行状态可在当前建议已变化时继续读取。
5. 明确拒绝的输入可纠正；超时或网络中断先读取原回执，不自动重复提交。已结束交易会继续核对资金费；有完整零结算区间证据后，页面显示完整纸面结果并恢复可用余额。
6. 下一笔先“重新读取模拟账户”，保存当前账户设置，再重新研究，使用新建议独立确认。旧建议不能授权下一笔；旧回执仍能回看原交易。

保存的“最大计划损失”按实际可成交数量、止损触发后的不利报价及双边交易费核对，超过上限则本次不成交。它是止损交易情景的计划约束；未来资金费、跳空和强平影响未完全包含，不能理解为保证最终损失不超过该数值。

24/72小时目前只支持研究与建议，不支持手动执行。跨结算点且缺少结算价格/时点持仓等原件时，资金费、净收益和胜负仍未知；账户可用余额可能保持未知，不能把它当作可继续开仓的授权。这项费用覆盖能力仍有缺口。
