## 问题描述

用户已经直接要求从 T-000 开始、完成 v3 全部任务；本轮将其视为对 T-000 的直接分配，不重复索要任务授权。但执行文件之间存在不能同时满足的 Git 规则。依据 `AGENTS.md:11`，在实施存档或切换基线前登记问题并停止任务实施。

1. `AGENTS.md:46` 禁止 `git add .` / `-A`，只允许暂存自己修改的具体文件；T-000 任务卡第 45 行要求 `git add -A`，并要求一次提交当前全部未提交工作，其中包含旧会话修改的文件。
2. `AGENTS.md:24` 禁止任何 `git push`；完整执行指令第 117 行、任务卡第 108 行要求普通推送。两者对普通 push 的要求相反。
3. T-000 第 76—92 行要求首次直接向 `v3/main` 提交文档，而同卡第 138 行禁止直接向 `v3/main` 提交。它可能是初始化例外，但没有显式定义。通用流程又要求从尚不存在的 `v3/main` 创建任务分支。

当前工作目录还承担旧系统开发 / 运行文件。按任务卡在原目录检出 9 月基线，会替换目录中的旧代码；`AGENTS.md` 又要求不触碰运行中的旧服务。建议明确允许在隔离工作区初始化 v3，原目录保留旧版本。
