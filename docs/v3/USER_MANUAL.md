## 1. 打开原工作台，先确认本机身份

日常使用启动器生成的 **“Decision Hub”本机快捷方式／私有入口**。进入“仓位与风险设置”，等待显示 **“当前身份”** 和 **“本机授权有效至”**，再操作账户或提交研究。直接输入普通页面地址不保证已连接本机身份。

需要维护人员启动时，在原项目根目录使用现有入口：

```powershell
pwsh -NoProfile -File .\infra\dsh\run-product.ps1
```

以启动器输出的 `DECISION_DESK_LOCAL_ENTRY` 打开本机入口；业务页面地址以本次启动器输出为准。保持启动窗口运行，停止时使用原 `stop-product.ps1`。若已有服务或启动器报告来源、版本、端口问题，应先由维护人员核对，不要重复启动或自行换端口绕过。

本机配对口令、私有入口和带认证信息的地址不要分享、截图或粘贴到报告中。DSH 页面是技术人员使用的研究轨迹控制台，普通操作仍在 Decision Desk 完成。

身份过期时重新打开原本机入口，等待身份及账户回读。恢复后继续核对原请求；身份错误不代表此前请求一定没有提交。

## 2. 选择或创建 PAPER 模拟账户

从“今日研究”进入 **“查看已保存设置并研究”**。

1. 按需点击 **“读取 BTC 合约元数据”** 或 **“读取 ETH 合约元数据”**。只有服务端核验后出现的合约才可选择；失败时保留提示，不手填替代原件。
2. 已有账户时，在“账户来源”选择 **“已保存的模拟账户”**，选原账户，再点 **“重新读取模拟账户”**，核对权益、可用保证金及仓位。
3. 确需新建时，在“用模拟资金验证方案”中明确输入 **“初始模拟资金（USDT）”**，选择模拟方式，并勾选模拟规则确认后，点击 **“创建模拟账户”**。本候选流程采用“看到方案后手动确认”。
4. 等待原创建回执确认，再使用该账户。结果待确认时先核对原回执，不重复创建。

初始资金是人为设置的虚拟测试资金，不是真实存款，也没有本手册规定的默认金额。创建账户本身不会开仓或开始成交；账户已保存但“纸面执行尚未就绪”时，应保留该状态。BTC／ETH 若使用同一账户，共享其资金与保证金预算。

## 3. 保存合约与风险设置

选择 BTC 永续 `okx:BTC-USDT-SWAP` 或 ETH 永续 `okx:ETH-USDT-SWAP`，核对账户和合约。按自己的测试意图填写最大名义暴露、最大计划损失、允许方向及效用／风险偏好；不要照抄历史截图的金额。

点击 **“保存设置”**，再点击 **“重新读取设置”**，确认服务端回读的是同一账户、合约和设置版本。未保存的表单修改不会自动成为研究输入。

名义暴露上限不是必须投入的金额，计划损失约束也不是极端行情下的损失保证。研究中的“比较单位”不等于账户余额或可执行下单数量。

## 4. BTC／ETH × 4／24／72 小时：一次提交一个研究

1. 在 **“预测期限”** 中选择 **4 小时、24 小时或 72 小时**。
2. 再核对当前账户、BTC／ETH 合约及已保存设置，点击对应的 **“研究 BTC 4 小时方案”** 等按钮。
3. 显示 **“研究请求已接受”** 后，点击 **“查看原研究进度”**，保留该次任务链接与原请求编号。
4. 结果待确认时使用 **“核对原研究回执”**；这只读取原请求结果，不另发一次研究。

同一设置的再次研究会产生新的任务，也可能产生新的模型用量。不要为刷新进度反复点击 **“重新研究当前已保存设置”**。改账户、合约、期限或设置后，应按新范围发起新研究，不能沿用旧报告当作新预测。

4／24／72 小时是预测目标窗口，不是预计等待时间。尤其 72 小时不表示已验证连续持仓 72 小时；资金费、保证金和退出仍需独立核验。

## 5. 排队、研究、审核与发布分别看

| 状态或提示 | 含义与操作 |
| --- | --- |
| `queued`／研究请求已接受 | 请求已入账，等待执行；还没有证明报告完成或审核通过。 |
| 研究进行中 | 留在原任务，可查看已收集证据；不要重新提交。 |
| 结果待核对 | 核对原回执；暂不能先当成功或失败。 |
| 阅读研究报告 | 打开同一次任务的报告，核对账户、合约、期限和设置版本。 |
| 需修改／审核未通过 | 保留真实审核意见；收到意见不等于获准发布或成交。 |
| `research_only`／仅研究、等待建议发布 | 可以阅读已有研究，但没有据此执行的资格。 |
| 本次研究未完成／失败／取消 | 查看原因与恢复，保留原任务和失败记录；不要用旧任务结果补成成功。 |

工具成功、证据数量、服务在线以及报告正文完整，都不能代替独立审核和真实发布。若显示“未独立审核”“未知”或“不支持”，按原样理解，不补成通过、0 或默认值。关闭标签页不等于停止研究；需要停止时使用原进度页的停止操作并等待真实终态。

## 6. 阅读同一次任务的报告

从原进度的 **“阅读研究报告”** 或建议中的 **“追溯原研究报告”** 进入。先核对任务、账户、合约、设置版本、保存时间和预测窗口，再读概率、证据、相反解释、未知项、成本假设与失效条件。

事件情景概率与“情景发生后的方向概率”是不同含义；空仓、已有多仓、已有空仓也是互斥的账户分支。主观概率不等于经校准胜率，历史报告也不会自动更新为当前行情。

若页面显示 `research_trial`、`paper_only`，或金融资格／执行授权为否，保留这些限制。研究报告不授权模拟成交或真实交易。即使以后出现可用的手动模拟入口，仍须独立核对当前建议、账户、报价、金额、退出保护和本笔确认；设置、创建账户、报告保存均不能替代它。

## 7. 保存 JSON／离线 HTML

报告完成身份和原件核对后，当前页面提供：

| 按钮 | 保存什么 |
| --- | --- |
| **下载已保存原件 JSON** | 服务端保存的报告原件，用于核对来源内容。 |
| **保存阅读快照 JSON** | 本次已核对报告的阅读数据副本。 |
| **保存离线 HTML** | 可离线阅读的正文及内嵌同一阅读 JSON；不带在线操作能力。 |

阅读副本不是完整审计封包，不会重新核验外部原件、更新研究、改变金融资格或授予交易权限。离线 HTML 不加载外部资源。**PDF 导出尚未接通。**

未出现按钮或无法导出时，按实际提示处理：

- **正在核对已保存报告**：等待本次读取完成；切换任务或本机身份后需重新核对。
- **尚未完成身份核对**：从原本机入口恢复会话，再重试读取。
- **无法核对原件或完整性**：暂不展示未经核对内容；保留原报告，重试读取或请维护人员核查。
- **暂时未能读取报告**：属于读取失败，不能认定原研究失败或重新生成报告。
- **旧版记录或尚无已保存报告**：不保证提供新的阅读导出按钮。
- **阅读副本尚未保存成功**：重新核对报告后重试；原报告和资格保持不变。

不要为了得到下载文件而重新提交研究，也不要将另一任务的 JSON 冒充当前任务原件。

## 9. 手动PAPER：准备、确认和查回执

以下按钮已在恢复后的原界面核对；当前试用账户仍显示尚未配置模拟执行，尚无可成交结论。服务显示“尚未配置模拟执行”或当前建议不可用时，不能据本说明推断可以成交。历史报告已过期时，先获得同账户、同合约、同期限的新鲜可用建议。

1. 在当前建议的“手动确认一笔模拟”中点“准备手动模拟”，核对账户、合约、期限、建议与设置版本。
2. 核对参考报价，必要时点“重新读取参考报价”。分别看“新入场许可截止”和“持仓最晚退出时间”：刷新报价不会延长入场许可，已有仓位仍受原退出保护管理。
3. 自行填写“最多入场名义金额（USDT）”“止损触发价（USDT）”“止盈触发价（USDT）”及“最晚退出时间（本地时间）”。按合约最小价格变动输入；“使用允许的最晚时间”取原协议实际T1，也可选更早退出。预测期限与持仓许可独立核验。
4. 核对金额和退出条件，勾选本笔模拟授权，再点“确认这笔手动模拟”。服务端仍核当前许可、报价新鲜度、价格格式和计划损失。
5. 结果未确认时点“读取原回执”，受理后点“读取模拟执行状态”。受理、成交、持仓、退出和结算分别看原记录；不要重复确认制造另一笔意图。执行进程状态未知时保留未知。

设置上限、研究比较金额、意图受理和实际成交金额分别保存。资金费未知不能当零，计划损失不保证跳空后的实际损失。4h／24h／72h软件支持不代表真实成交或持仓恢复验收。

## 10. 到期结果与复盘

在原研究入口对同次任务点“读取到期结果”，核对目标窗口、实际类别和收益定义。窗口未成熟、原件缺失或采集未完成时保留pending／unknown，不能用当前行情补成历史终点。页面读取查看已保存结果；持续采集需要运维侧正常运行realtime角色。

结果与原预测分别保存，复盘不覆盖原概率、审核和时间。本次Windows授时已复测成功，旧未同步记录仍按原时间保留，不追认14天或四周认证。更多样本与分层报表仍需实际积累。
