# ADR：资料正文进入研究上下文与逐任务授权

日期：2026-09-30。状态：已实施、0053已部署，真实运行验收以唯一执行台账为准。

## 发现

真实美联储日历上传解析770段且审核通过，但没有观点候选；原ResearchRequestFactory只投影AnalystClaim，资料被选择却没有正文输入。研究任务创建与资料选择原为两次提交，存在先执行、后绑定及错误请求留下任务的风险。

## 决定

1. 审核ready的版本提供正文片段和候选，保留自然段序、页/块locator与字符偏移；有修改时按审计block_id和原文匹配应用，不能按全文行数zip。公开日历不能为进入研究而捏造观点。
2. 每片正文含来源标题和“待独立核验”的说明，≤4000字符。Context policy仍控制总输入预算，当前总计12项含任务触发；被排除的片段保留在context manifest。不是把整份长文都送入模型的保证，也不等同完整阅读或引用。
3. 原发布时间未知仍为null，观测和接收时间沿用资料版本；原件hash与片段hash分开。资料不会被标成新采集的官方市场数据，不产生typed facts，不绕过发布/Gate/方向证据要求。
4. local_only资料默认不允许传往外部AI服务，正文与观点一视同仁。显式selected请求可勾选仅本Run的allow_remote_library_content；不改变资料全局隐私模式，不继承给后续自动复查。上传时已有remote_allowed的版本可沿已有授权使用。auto不得通过该单次标记扩大私有资料范围。
5. 新Run、Observation和scope在同一事务提交；非法选择/未授权时整体回滚。scope以请求hash固定，重试不得替换版本、范围、问题或授权。页面相同载荷失败重试复用幂等键。
6. 研究请求构建时保存实际选入的片段文本、片段SHA-256、原件SHA-256和定位。此回执证明请求输入内容，不声称模型已理解或报告已引用。报告分开显示选择记录、已纳入片段数、预算排除数，并可展开核对原文片段。
7. 0053仅给research_run_scopes添加列。旧scope新增授权为false、输入为空；旧报告不追溯回填。新输入失败不能靠修改旧scope绕过，应由用户创建新的明确请求。

## 验收

后端覆盖0候选资料、正文定位/原时刻/哈希、预算选入与排除、未授权拒绝、任务事务回滚、选择不可改写、实际Request与回执逐字相同；0052→0053保留历史且不追授权。前端覆盖默认禁用、显式勾选和失败重试键。真实公开来源任务须检查输入回执、DSH执行和最终报告，人工结论质量另行评估。
