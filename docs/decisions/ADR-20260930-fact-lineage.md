# 原始材料、事实版本与跨研究复用

日期：2026-09-30。状态：实施中；正式迁移和在线验证以执行台账为准。

## 边界

- 保留现有每个 Run 的 Evidence / Fact，不移动、不覆盖原报告引用。新增 RawCapture → ParsedVersion → FactVersion → RunInputRef 的只追加投影。
- RawCapture 保存真实 HTTP 响应体的内容寻址文件及服务器时间、状态、哈希；失败响应也保留。URL 去认证信息，只保存允许的业务查询参数。测试注入 fetcher、历史缺失文件不伪造 HTTP 回执。
- ParsedVersion 显示两种不同关系：同一次工具调用取得的原始输入集合、已有原文存档引用。输入集合可用于重放解析，不等于每个正文句子已经人工核实。保留解析代码指纹；无存档明确 unarchived。
- FactVersion 的范围含 Study 市场/品种和事实自身 instrument / venue / unit；相同名称不足以合并。版本固定值、有效窗口、来源、解析关系。RunInputRef 固定本次使用哪个版本及采用时刻。
- `known_at` 至少为原始接收与当时采纳时间的较晚者；`recorded_at` 是建立新投影的时刻。回填不能拿今天的时间冒充历史事实，也不能把过去发布日期当作当时已接收。
- 历史 as_of 检索要求版本 known_at 与内容时间都不晚于 as_of；新增晚到修订不能改变旧 Run 引用。先按时刻筛选，再按相同业务键选版本，不能先取当前最新版。

## 复用准入

先实施明确、保守的精确请求复用：同一市场/品种、相同能力/字段/符号/事件窗口/检索条件/允许域与当前配置指纹；只允许已审核的公开数值能力，保留原来源独立性。最多 30 秒，所有事实及证据必须已采纳且原始输入可验证。私有资料、搜索摘要、未知范围、event-window 和 replay 不进入此缓存。

复用 Adapter 位于现有 Gateway 内，因此能力开关、授权、超时、允许域、内容哈希、PIT、质量和持久 Run 归属校验仍照常执行。每次使用生成当前 Run 的 Evidence / Fact ID 与采用引用，保留原始观察时间与版本；命中不伪装为新抓取。当前供应商/解析代码指纹改变即失效。30 秒过期或任一原始文件损坏则正常重新抓取，不能用缓存掩盖外部不可用。

## 兼容

旧数据能从既有 URL/hash/正文引用追溯到的材料继续显示；缺少原始响应的标为缺失，不宣称完整原文存档。回填工具必须备份、两次幂等、旧表逐行哈希一致。外部数据尚未实时可用的情况保持失败状态。
