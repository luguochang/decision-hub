# 研究观点、发布结论、执行权限与后验观察

日期：2026-09-30。状态：实施中。

## 冻结对象

`AnalyticalOutlook` 保存原始判断与核验状态；`PublicationDecision` 保存原质量门的发布结果；`ExecutionPermission` 保存权限，当前产品没有下单通道，因此仍为关闭。三者在 Artifact 发布事务内写入，不能因研究受限而丢掉原始判断，也不能因保存观点而放宽交易门。

- AI 综合判断按原 30m / 24h / 72h 单独保存；原始 subjective_probability 与是否已校准分开，未持有匹配有效凭据不能显示已校准。
- 7d 日线规则只从受管历史能力的有效策略回执获得，方法版本单独统计；与 AI 综合判断和反方解释不混算胜率。
- 输入为冻结的 Evidence / FactVersion / Snapshot 引用，绑定结果哈希与对应复核回执。自动覆盖检查保留 bounded，不能升级成独立审核 accepted。
- 历史回填保留当时内容但标为 retrospective，不进入新建的前瞻样本集。新前瞻记录必须在窗口开始时写入，不能观察到结果后补登记。

## 时间契约

- 研究执行 deadline / 工具允许的接收截止，不是“当前已有证据截至”。可信 `data_as_of` 只能来自已接收的证据时间且不晚于冻结时间。
- 原模型正文保留。检测到“截至 / as of”声明晚于冻结时刻时记录错误，不能把这一版本作为有效前瞻判断。提示词也需明确禁止使用执行 deadline 描述已知证据。
- 到期窗口由冻结时刻起按声明时长计算，分别 30 分钟、24 小时、72 小时、7 天；原模型 expires_at 另留在原始载荷供审计。已经过期的判断不得通过重算窗口续命。
- 历史行情标签必须带供应商实际采样时刻，不能把请求时刻写成观测时刻。分钟收盘价是 close_1m，不是 VWAP 或真实成交。

## 观察资格与统计

观点未通过发布门仍可进入观察，但必须范围明确、有当前 Run 的已采纳引用、时间合法、材料可定位。缺少校准不影响记录非概率的方向观察；不完整、无方向、时间错误等保留排除原因。

- long / short 的符号收益按公开且固定的规则计算；neutral 只记录实际市场收益，不自动认定方向命中；no_trade 没有方向预测资格。
- 估算蜡烛窗口与 observed 数据分层；估算标签不能用于宣称交易可执行或完成校准。
- 方法、窗口、市场、品种、前瞻/回填、数据质量分别成组；样本不足和未到期如实展示，不补造未来标签。延迟任务、失败原因、重试时刻落库。
- 原 Forecast / Outcome 与旧深链继续有效；新观察集不改变旧指标分母。

## 验收

覆盖：发布关闭但观点留存；一次提交幂等；复核版本不匹配；未来时间声明；晚到修订不改旧观点；7d 与其他窗口分组；neutral 不伪造命中；行情时间错位拒收；过期任务重试；正式新报告和真实读取。长期前瞻标签成熟属于数据条件，不能用回放冒充。
