# 正式研究方法身份与演进版本生效

日期：2026-09-30。状态：accepted（边界与实施方向）；部署消费链路仍待实现。

## 已核实的现状

- `build_evolution_worker` 和 `build_prospective_worker` 使用 AgentRuntime 的单次方向综合；默认实现为 LangGraphAgentRuntime。
- 正式 `build_research_worker` 使用 ResearchHarnessRuntime，当前受管配置为 DshWebResearchRuntime。它会采集资料、调用工具、综合和复核。
- 演进的 `active_pointers` 被评估规划读取，正式研究 Worker 没有读取并应用该候选。指针更新不能证明方法已部署。
- DSH SessionLink 已固定请求哈希和 Host 构建身份，Prompt 表保留各代提示；先前没有独立冻结 Hub 提示/上下文规则的执行前凭据。

## 本步已实现的边界

在已有 `run_role_outputs` 保存 `research_execution_method`：Host 接收前记录请求哈希、运行适配器、提示规则与上下文规则代码哈希、已核验 Host 构建、范围/角色/能力/预算。重试与后续轮次必须匹配；原文、密钥、服务商 URL 不进入此凭据。

上下文选择回执随证据补齐而变化，属于每轮输入，保留在对应 Prompt；方法身份固定选择规则代码，不能因为选中材料变化阻断正常研究。工具剩余额度也不能生成新方法身份。

既有 Session 缺执行前凭据时保持未核验，禁止用今天的代码补记旧运行。当前实现覆盖正式 DSH Web 路径；SDK/Replay 不能被推断为具有同等方法凭据。

此凭据**尚不包含 Host 实际 Provider 配置、完整外层流程/Pack 的内容身份，也未消费演进候选**。字段 `provider_configuration_attested=false`、`evolution_pointer_consumed=false`、`candidate_id=null` 保留这一事实。不得把它作为已经完成正式部署或可以晋级的证明。

## 必须继续实现的约束与验收

1. **目标范围显式化**：单次方向综合、完整研究 Harness 分别登记。历史候选和结果保留原范围，不能原地改名后作为 DSH 证据。
2. **完整运行定义**：Host 回报真实加载的 Provider/模型/端点摘要、预设、工具权限、提示/外层流程/Pack 内容版本；凭据使用内容哈希且不得含密钥。Hub 期望配置不能代替 Host 实际加载配置。
3. **部署与审核分开**：审核通过形成待部署状态。Host 确认实际配置、Worker 可消费后，才能显示“正式研究已生效”；失败保留原有效版本及错误。
4. **Run 级固定**：新 Run 固定已确认方法；在途任务、恢复任务继续原方法。配置不匹配在新的模型提交之前拒绝，不能静默换方法继续旧任务。
5. **凭据读取一致**：报告、研究观点、对照实验、回滚记录引用同一实际方法身份，不能以 strategy_version/profile 名称相同认定内容一致。
6. **真实验收**：审核→部署→新研究→结果方法匹配；在途运行保持；中断恢复与回滚；错误配置、缺制品、旧研究缺凭据均有准确状态。保存 PC 操作和后端审计证据。
